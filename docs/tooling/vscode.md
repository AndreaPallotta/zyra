# VS Code Extension

Official VS Code Extension for the Zyra Programming Language.

---

## Features

- **Syntax Highlighting**: Keywords, types, strings, string interpolation
- **IntelliSense**: Autocompletions for keywords, types, and stdlib
- **Hover Docs**: Markdown API signatures and tooltips
- **Code Lens**: Interactive `▶ Run Native Zyra Binary` button above `def main()`
